Quran Recitation Checker

Recite out loud. Reading mode shows the ayah; No-look mode hides it and shows only the word you missed.

✦
How to use
  1. Choose a surah, the ayah to start from, and a mode, then press Start and allow the microphone.
  2. Reading mode: the ayah is shown. No-look mode: it is hidden, and you only see the word you missed. Qari mode: the reciter plays an ayah and you repeat it.
  3. A wrong word gives a beep. The ayah is played, and an ayah is never skipped until you recite it fully.
  4. Tap the ayah card to show or hide the English translation.
  5. Use Chrome or Edge, and open the page over https so the mic is only asked once.
⚙ Settings

Install on your phone: Android Chrome menu, then Install app. iPhone Safari: Share, then Add to Home Screen. The page must be on https.
